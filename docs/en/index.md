## Where to begin

- First installation: follow the [quick start](/en/getting-started/quick-start).
- Existing deployment: use the [user guide](/en/guide/) and [operations guide](/en/operations/).
- Runner or module development: start with the [developer guide](/en/developer/) and [architecture overview](/en/architecture/).

Everything under `docs/` is maintained as public documentation. Host addresses, temporary credentials, and one-off validation logs belong in controlled issues, CI artifacts, or an external private system; promote stable conclusions into current guides, references, or design documents.
