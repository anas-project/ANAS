# Getting Started

This section is for a first ANAS deployment. At the end you will have a workspace that can be managed, backed up, and rolled back as one unit.

1. Read [installation and requirements](installation.md).
2. Follow the [first deployment](quick-start.md).
3. Continue with the [user guide](/en/guide/) for configuration, normal operation, and recovery.

If a workspace is already running, go directly to the [complete task guide](/en/guide/usage).
