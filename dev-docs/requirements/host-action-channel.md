# 宿主特权动作通道要求

本文规定安装期那一次 root 之后，Web 控制台与 CLI 如何执行需要特权的宿主操作。设计见
[宿主特权动作通道](../../docs/architecture/host-action-channel.md)；线格式与 job 语义由
[统一动作 ABI](action-abi.md) 规定，本文不重复。

这些要求最初写在 [Incus Module 要求](incus-module.md)里（`INCUS-R-058` 等），因为它们是被 Incus
的宿主供给需求撞出来的。但它们**没有一条是 Incus 的要求**——通道服务于任何需要特权宿主操作的
功能，因此迁到本文并重新编号。

关键词“必须”“不得”“应该”具有规范性。ID 一经分配即固定，废弃的需求保留行并标 `已废弃`。

## 1. 为什么需要它

ANAS 是面向普通用户的产品，命令行安装完成之后日常操作应当都在 Web 端完成，但装 Incus daemon
一类操作需要 root。三条路里只有一条成立：Web 端要密码**禁止**（与钓鱼形态无法区分，且授予整机
控制权）、每次回终端 `sudo` 与产品定位冲突，因此是**安装期一次授权、之后经受限通道执行具名
动作**。

关键性质：用户给出的是一次性的安装授权，**不是一个可以随意提权的通道**。通道能做什么，在安装
那一刻就固定了。

## 2. 范围

必须包含：通道形态与不变量、授权与审计、二段确认、动作清单治理、非 systemd 可移植性。

不要求：把 `anas-helper` 并入本通道——它是唯一真正窄的能力（`CAP_NET_ADMIN`、无特权产物、每次
apply 都走），保持独立唯一买到的就是「日常热路径永远碰不到 root-capable 的文件」。

## 3. 需求矩阵

| ID | 要求 | 验证方式 |
| --- | --- | --- |
| `HOSTACT-R-001` | 特权通道只接受动作 id 与类型化参数，动作实现必须编译进 root 二进制；不得接受调用方提供的命令、argv、路径或脚本，也不得执行位于 anas 可写目录中的文件 | 审阅 + 安全测试 |
| `HOSTACT-R-002` | 特权通道必须 socket 激活而非常驻 root 进程，校验对端 uid/gid，并逐次审计动作 id、规范化参数、调用方与结果；敏感参数不落日志 | 单元 + 安全测试 |
| `HOSTACT-R-003` | 每个特权动作必须有对称的撤销动作；`incus.install` 之所以可接受正是因为 `incus.uninstall` 存在 | 审阅 + e2e |
| `HOSTACT-R-004` | CLI 与 Web 必须共用同一条特权通道与同一份审计记录，能力差异不得来自入口 | 审阅 + e2e |
| `HOSTACT-R-005` | 特权入口只有两个：`anas-helper`（`CAP_NET_ADMIN`，日常热路径，无产物）与 `anas-hostd`（完整 root，罕见、有产物、逐次审计）。不得为 `CAP_SYS_ADMIN` 单开第三个入口 | 审阅 |
| `HOSTACT-R-006` | `anas-hostd` 必须与 `anas` 同版本发布并一起升级；不得存在可单独更新的动作目录或可写入的脚本目录 | 静态 + 审阅 |
| `HOSTACT-R-007` | 特权通道的长时动作必须支持进度回显；调用方断连时的语义必须由与 Module Command 共用的 job 模型定义，不得让宿主通道另造一套 | 契约 + 审阅 |
| `HOSTACT-R-008` | 非 systemd 发行版上常驻部分必须只做 accept，动作逻辑仍在每请求短命进程中执行；不得改用 setuid 二进制 | 审阅 |
| `HOSTACT-R-009` | 确认 token 有效期 5 分钟且一次性消费；`/run/anas/` 只存 token 摘要与被批准动作的摘要，不存 token 本身 | 单元 + 安全测试 |
| `HOSTACT-R-010` | 确认 token 属于动作 ABI 而非 HTTP 层：CLI 与 Web 的 plan/apply 用同一机制，并留下同一对互相引用的 job 记录 | 契约 + 审阅 |
| `HOSTACT-R-011` | token 过期后 `apply` 必须重新 plan 并重新展示摘要要求再次确认，不得沿用旧摘要执行；客户端应在用户停留过久时静默换新 token 而不是延长有效期 | 单元 + e2e |
| `HOSTACT-R-012` | 新增宿主特权动作必须按需求级变更评审：拿需求 ID、进矩阵、回答五问（能否不用 root、权限是否最小、留下什么特权产物、有无对称撤销动作、失败到一半的状态与重跑是否收敛） | 审阅 |
| `HOSTACT-R-013` | 动作清单必须可打印（`anas host actions`），使运维不读源码即可审计该二进制能做什么；从未被调用的动作必须定期复审并删除 | 契约 + 审阅 |
