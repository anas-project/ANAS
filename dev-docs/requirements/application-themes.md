# 应用图标与可导入主题要求

2026-10-20 用户确认补齐应用图标、提供原始与统一风格两套内置主题，并支持管理员导入、全站可选。
门户的浅色、深色、跟随系统及账号偏好已经实现，本主题在其上扩展，不重做既有能力。
实现取舍见[设计](../../docs/architecture/application-themes.md)，执行与证据见[计划](../plans/archived/application-themes.md)。

## 范围与事实来源

图标覆盖所有声明 `applications` 的内置 Module，包括用户与后台管理入口；没有网页入口的后端服务不虚构应用。
优先使用官网或项目官方仓库的高清原始素材，可缩放矢量同样属于高清来源。确实没有合适高清标志时，
按原始标志重绘，明确记录来源、原件摘要和生成方式，不能把生成稿标成官方原稿。
默认原始图标仍由各 Module 声明，复用应用目录的七档 PNG、冻结制品与授权规则。

第二套内置主题保留应用辨识度，统一图标视觉，并提供与导入主题相同的可移植主题包。
主题包只描述名称、配色、图标和出处，不是可执行扩展；不接受任意 CSS、JavaScript、HTML、SVG 或运行时外链。
配色继续遵守 PORTALUX-R-005；应用授权、链接和业务元数据继续只由应用目录决定。

## 管理与选择

ANAS 管理员可以通过门户导入主题，供全站用户选择；普通用户与仅受限委派人员不能导入。
用户的个人主题选择按身份锚点保存，明暗模式与图标主题分别选择；导入不会改变其他人的选择。
主题文件进入门户现有私有数据卷，随 data 备份，不新增服务或数据库。

Casdoor 原生应用只有一个全站 logo，不能逐用户跟随门户选择。用户确认全站默认图标主题同时用于门户和 Casdoor；
个人覆盖只影响门户。修改全站默认通过 ANAS 配置和原生 apply 生效，门户提供可导出的主题包与配置说明，
不持有 IAM 管理写凭据、不写宿主 workspace，也不在导入时暗中发布 Casdoor 配置。

## 需求矩阵

| ID | 要求 | 验证方式 |
| --- | --- | --- |
| `APPTHEME-R-001` | 所有声明网页应用的内置 Module 必须提供该应用的专属图标源，不能继续使用通用占位图 | CI + 审阅 |
| `APPTHEME-R-002` | 图标必须记录官网或官方仓库出处及原件摘要；重绘稿必须明确标记并保留所用原图与生成说明 | CI + 审阅 |
| `APPTHEME-R-003` | 系统必须提供原始及统一风格两套内置图标主题；统一风格包可导出并经同一导入协议重新导入 | 单元 + 界面 |
| `APPTHEME-R-004` | 门户主题导入必须只允许当前 ANAS 管理员并校验 CSRF；匿名、普通用户及仅受限委派人员不得写入 | 单元 + e2e |
| `APPTHEME-R-005` | 导入必须拒绝未知字段、可执行内容、外链图片、非允许的图片格式、非法配色和超限数据，不得更改应用权限或 URL | 单元 |
| `APPTHEME-R-006` | 导入失败不得损坏已有主题；重复导入相同内容应保持一致，不得静默覆盖同名不同内容 | 单元 |
| `APPTHEME-R-007` | 导入主题必须持久保存在门户私有数据卷，重启后仍可选择；损坏主题应被隔离并报告，不得被当成可用主题 | 单元 + e2e |
| `APPTHEME-R-008` | 用户的图标主题选择必须按账号保存并在另一浏览器生效，明暗模式选择保持独立 | 单元 + e2e |
| `APPTHEME-R-009` | 未被主题覆盖的应用必须保留原图标；不存在或不再可用的个人主题选择必须回退全站默认并明确提示 | 单元 + 界面 |
| `APPTHEME-R-010` | 主题列表不得泄露未授权应用清单；主题图片必须复用所属应用的当前授权检查，未授权用户不能读取 | 单元 + e2e |
| `APPTHEME-R-011` | 全站默认图标主题必须通过同一冻结应用目录应用于门户和 Casdoor 原生 logo；个人主题选择不得更改 Casdoor 全站 logo | 契约 + e2e |
| `APPTHEME-R-012` | 自定义全站默认主题的内容变化必须影响原生计划摘要，并把实际图标冻结到部署制品，不能在运行时依赖原始导入文件或联网下载 | 单元 |
| `APPTHEME-R-013` | 导入包只能供全站选择，导入动作不得自动改变其他用户偏好或执行 ANAS apply | 单元 + 界面 |
| `APPTHEME-R-014` | 主题选择、导入结果、回退提示和配置说明必须覆盖门户现有八种界面语言，且 390px 下可操作 | 界面 |
| `APPTHEME-R-015` | Casdoor 中各 Module 应用、门户登录/再次验证及 Provider 自有登录页必须有高清专属 logo；使用共享512px圆角PNG，隐藏门户品牌不得生成可见自链或扩大访问权限；创建Module文档必须规定图标来源与声明 | 契约 + 界面 + e2e |
| `APPTHEME-R-016` | 从门户进入 IAM 登录时必须把当前解析后的深浅色通过原生 theme=dark/default 传入；系统模式在导航时解析；非法参数不得影响 OIDC 安全字段 | 单元 + 界面 + e2e |
