# 目录主邮箱与门户建号要求

状态：用户已确认系统生成主邮箱、独立邮箱后缀、迁移已有默认地址、门户新增建号和限定人员 OU；目录侧与门户实现、实机验收完成，结果见配套归档计划。

Samba AD 的单值 `mail` 保存系统管理的主地址。默认规则为用户名加邮箱后缀；后缀未指定时继承目录域。邮件后端接入后消费该地址，本轮不代表邮箱已开通。门户和 LAM 不接受手工主地址。用户于 2026-10-17 进一步确认邮箱整栏由系统管理，因此不再维护手工主地址例外或来源认领方案。

门户前台以 ANAS 管理员角色授权，后台使用可配置的创建绑定；默认准备独立受限账号，仅授权指定人员 OU。指定其他已授权账号也受支持；若使用域管理员，门户进程会长期持有该账号既有权限，不能再宣称整个进程不持有域级凭据。finance 使用默认受限账号。人员管理和新建范围均为目录 Provider 指定的用户 OU 及子 OU。域级组授予仍沿用本人域权限与逐次验证。

本矩阵是规范来源，正文是解释。两者冲突以矩阵为准。

| ID | 要求 | 验证方式 |
| --- | --- | --- |
| `MAIL-R-001` | 邮箱后缀必须可独立配置，未指定时继承目录域，修改不能重命名 AD 域、UPN、登录名或稳定身份 | 单元 + e2e |
| `MAIL-R-002` | Samba 初始化创建日常管理员时必须直接写入按默认规则生成的 AD mail 字段 | 单元 + e2e |
| `MAIL-R-003` | 门户创建人员时必须同时赋予系统生成的主邮箱，不接受手工邮箱或任意目标 DN | 单元 + e2e |
| `MAIL-R-004` | 指定人员 OU 的主邮箱必须由系统维护；后缀修改须覆盖该范围的既有系统主地址，范围外和服务/信任/计算机对象不参与 | 单元 + e2e |
| `MAIL-R-005` | 门户及 LAM 的人员页面不得提供手工主邮箱写入；未接入邮件后端时不得声称收件箱已开通或地址已验证 | 契约 + e2e |
| `MAIL-R-006` | 邮箱规则处理发现非法用户名、已登记地址冲突或写入失败时必须显示真实失败，不得静默改写登录名或宣称迁移完整成功 | 单元 + e2e |
| `MAIL-R-007` | 邮箱后缀迁移必须保留身份、组、密码和其他人员字段，结果及未完成状态须可核验，不得增加独立邮箱数据库或同步服务 | 契约 + e2e |

范围外：邮件后端、邮箱数据、SMTP/DNS 开通、个人别名与主地址手工改名。目录字段维护复用现有 Anchor Worker；不新增 Casdoor 源码补丁。建号权限、密码和审计的门户判据见 PORTAL-R-062—R-067。
