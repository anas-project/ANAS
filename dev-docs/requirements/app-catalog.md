# 应用目录要求

需求方向已确定，功能尚未实施；Casdoor 页面/API 扩展的具体实现选择待确认。
本文规定用户和管理员在 IAM 门户发现应用的行为，包含非 IAM 登录应用与手工配置的外部条目。
协议设计见 [应用目录](../../docs/architecture/app-catalog-design.md)，验证依据见
[固定 Casdoor 调研](../../docs/research/casdoor-app-catalog.md)，交付见 [计划](../plans/app-catalog.md)。

## 1. 条目与信息

目录条目代表人员入口，不能只从 IAM client 推导。一个 Module 可以提供多个入口；
没有人员入口的 Module 显式说明不发布。应用身份使用稳定应用名，显示名允许调整。
每个有效条目必须有显示名、入口、简介、详细描述、文档地址、完整图标尺寸、权重与分类列表。
目录描述不会改变服务是否可用，不能用健康探测结果隐藏授权问题。

用户可修改展示配置，但不能借此改变 Module 的入口用途、真实执行点和准入规则。
外部应用直接写进 workspace 配置，采用同一套元数据和过滤模型，不要求制作 Module、接入 SSO、
人工操作 IAM 后台或生成无用途的 OAuth 凭据。链接必须保持其 query 和 fragment。

### 1.1 多语言

应用目录首期接入简体中文 `zh-CN` 和英文 `en`。应用显示名、简介、描述、文档地址，
以及分类显示名和描述都使用语言映射；门户操作文字也需中英文。内置条目与分类文案须双语完整，
品牌名可相同，文档无译版时两种语言可指同一有效地址。外部条目与自定义分类允许单语输入，
通过逐字段回退避免空白；不要求管理员为添加一个外部链接先翻译全部文案。

语言来源依次取用户门户选择、浏览器首选语言、全局默认语言和英文，仅在来源缺省时继续。
所选语言不受支持时必须直接使用英文，不再尝试较低优先级来源，即使部署默认是中文也一样。
字段缺译依次尝试选定语言、英文、简体中文。外部项每个必需字段至少有一个非空有效值；
仅有中文的外部字段仍可显示原文，这不改变门户已选定的英文语言。
语言键及区域语言匹配详见设计 §2.1，首期不宣称支持繁体中文或其他语言。
配置覆盖按字段与语言键合并，修改中文不能擦掉原英文。

稳定应用名、分类 ID、入口链接、排序、权限和七档图标各语言共用。切换语言不产生新应用，
不改变可见条目，也不需要重新登录、写数据库或部署。完整翻译进入不可变目录制品；
用户 API 在授权过滤后解析语言，缓存不能在用户或语言间串用。

## 2. 文件交付

图标提供 16/32/48/64/128/256/512 七档，能够在小图标和高像素密度屏幕显示。
输出采用可校验 PNG；可由足够大的本地源图生成缺少尺寸，并允许小尺寸单独设计。
缺省图标是明确的统一资产，不能依赖各 IAM 随机回退。

文件共享采用有作用域的只读 deployment 制品；发布者不暴露整个 Module、data 或 Secret 目录。
消费者读取同一版本的元数据与图标，路径分别区分渲染、宿主、容器和浏览器。
图标内容是部署输入，单改图片也必须产生变更；回滚读取旧部署自己的完整资产。
目录中的真实 URL 与权限信息不能作为公开静态文件泄露。

## 3. 权限

Casdoor 是主力 IAM；权限语义以固定版本资料、源码和实验为依据。
第一版只提供正向组允许列表及映射到目录组的 platform_admin，不宣称支持任意权限脚本。
缺失规则、空允许组、未知组、失效策略及不支持的条件不能退回允许所有人。

过滤在服务端完成，先排除未登录/无效用户及隐藏/禁用条目，再执行明确权限检查。
目录管理员不自动绕过 hidden 或显式组过滤。关联 IAM/网关的入口必须从真实执行点派生规则；
本地登录和外部条目只能宣称过滤目录，不能以“看不见卡片”代替目标的访问控制。
组撤销后重新读取目录必须反映当前 IAM 组事实，缓存不能跨用户或延长已观测撤权。

Adminer 必须有 platform_admin ForwardAuth 与数据库账号登录两层；不能用数据库超级用户
自动登录取代任一层。管理入口无论放在哪个展示分类，都不得对普通应用组开放。

## 4. 交付范围与 Provider 方向

产品未发版，新目录协议直接替代 APPS_LIST，不设计兼容桥、双写或旧字段迁移。
这不授权删除业务数据或静默切换 IAM 身份绑定。
Casdoor 首先完整交付全部字段和安全语义；Authentik 逐步弃用，冻结新增目录功能，
安全维护与最终移除条件明确记录。LLNG 按能力另行验收；未验证的适配不能标为已支持。

所有现有 Module 都进入人员入口盘点，新 Module 同步声明入口或不适用原因。
源码实验只证明固定函数行为；完整支持必须同时验证生成配置、真实 API/浏览器、权限反例、
图标加载、入口点击和 Adminer 双层认证。
