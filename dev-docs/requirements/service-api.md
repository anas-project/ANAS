# anasd 服务授权与门户后台凭据要求

用户于 2026-10-23 确认实施：调用服务负责最终用户授权；anasd 以独立服务令牌认证
调用方，并限制 API 和资源范围。门户作为首个调用方，沿用现有 5 分钟本人认证。
令牌由 anasd 自动续期和文件交付；门户长期停止或宿主重启后自动取得有效令牌。
设计与当前操作说明见[服务 API](../../docs/architecture/service-api.md)，结果见[计划](../plans/archived/service-api.md)。

## 范围和理由

一个门户部署使用一套服务令牌，其他服务各自登记身份并复用同一机制。anasd 信任
已授权服务作出的用户授权决定，不接收用户目录密码，不将服务提升为控制台 owner。
权限和目标范围由宿主控制，调用方报告的用户身份只用于审计关联。

anasd 维护专用凭据文件并只读交付给门户，避免旧令牌失效后无法启动认证的循环。
停用/删除授权与自然过期有不同含义：前者不能被自动续期或重启恢复。
此交付方式针对当前同宿主部署；远程传送凭据不在本轮范围。

门户仅展示已明确登记凭据的本地后台。Traefik、DDNS-Go 使用已有本地管理员账号，
Collabora 使用其当前生效的管理员配置。LAM 的目录用户密码、IAM 应用的恢复账号、
ForwardAuth 入口和外部条目均不能被“没有 OIDC”这一推断自动纳入。
现有控制台用户认证与一次性 step-up 规则继续适用原接口。

## 需求矩阵

本矩阵是规范来源，正文是解释。两者冲突以矩阵为准。

| ID | 要求 | 验证方式 |
| --- | --- | --- |
| `SVCAPI-R-001` | anasd 必须以每调用服务独立的令牌识别服务身份 | 单元 + 契约 |
| `SVCAPI-R-002` | anasd 必须在同一授权条目内匹配 API 权限、工作区和目标对象，未匹配请求拒绝 | 单元 + 契约 |
| `SVCAPI-R-003` | 服务身份不得取得控制台 owner 身份或使用控制台用户会话接口 | 契约 |
| `SVCAPI-R-004` | 服务授权必须由宿主管理，workspace 配置或恢复不得扩大或恢复已撤销授权 | 单元 + 审阅 |
| `SVCAPI-R-005` | anasd 必须在门户未运行时仍自动续期已启用服务的令牌 | 单元 |
| `SVCAPI-R-006` | anasd 启动、令牌过期或交付文件丢失后，必须为仍启用的客户端自动交付有效令牌 | 单元 |
| `SVCAPI-R-007` | 停用或删除客户端后，anasd 必须拒绝其读取请求且不得自动补发令牌 | 单元 + 契约 |
| `SVCAPI-R-008` | 服务令牌必须通过仅对指定客户端可读、客户端不可写的专用文件交付，不进入浏览器 | 单元 + 契约 |
| `SVCAPI-R-009` | 服务 API 必须拒绝非 TLS 或非 full 状态的凭据请求 | 契约 |
| `SVCAPI-R-010` | 后台凭据读取必须由当前生效部署的显式本地后台声明确定来源，拒绝隐藏、禁用、IAM 和未声明条目 | 单元 + 契约 |
| `SVCAPI-R-011` | 凭据读取必须返回当前生效的用户名和密码，轮换或部署切换后不得继续返回旧值 | 单元 + 契约 |
| `SVCAPI-R-012` | 门户必须逐请求按当前用户身份、管理员权限及应用可见性判断是否允许获取凭据 | 单元 + 契约 |
| `SVCAPI-R-013` | 门户必须复用现有 5 分钟近期认证，过期后要求验证本人密码再获取凭据 | 单元 + 契约 |
| `SVCAPI-R-014` | 门户必须提供用户名、密码各自复制入口，关闭或离开结果弹框后清除页面中的凭据 | 契约 |
| `SVCAPI-R-015` | 服务令牌和后台密码不得进入应用目录、偏好、URL、普通日志或审计内容 | 单元 + 契约 |
| `SVCAPI-R-016` | 凭据交付前必须成功记录服务身份及目标的审计，调用方提供的用户标识不得扩大授权 | 契约 |
| `SVCAPI-R-017` | 门户必须拒绝不满足现有 CSRF/Origin 边界的凭据请求 | 契约 |
| `SVCAPI-R-018` | 门户必须在服务或令牌尚未就绪时报告不可用，并在令牌就绪后无需重新部署即可恢复获取 | 单元 + 契约 |
| `SVCAPI-R-019` | 后续 Module 接入标准必须要求适用的非 IAM 本地后台实现凭据获取与复制，明确来源、授权边界、验收和不适用说明 | 文档 + 审阅 |
| `SVCAPI-R-020` | 必须在用户指定 finance.hlong.wang 的 10000 门户部署并验证本功能，记录真实服务调用、管理员获取/复制、后台登录和令牌恢复结果 | 实机 |
