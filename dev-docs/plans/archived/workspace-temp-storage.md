## 历史设计与停止审阅的结论

范围限 Module 显式声明的临时目录。路径修改采用全量停启，不复制临时内容；历史回滚重新分配租约。复用 workspace 排他锁、依赖顺序和正常停止入口，引用或实际绑定未知时保留目录。应用负责保存，Core 不新增 WOPI 保存确认或编辑会话排空；Runner 系统临时文件、失败 job 保留和远程测试产物管理不在本范围。

2026-10-02 的 TEMP-R-042 / TEMP-T-009 人工审阅确认：`activateDeployment` 调用完整旧 Module 顺序，`stopModules` / `stopRelease` 逆序执行 `beforeStopModule` 后 Compose down；钩子失败中止。Collabora 正常停止等待 180 秒，入口清空补充组并降为 UID/GID 1001 后 exec coolwsd，使其直接接收停止信号。外来 workspace 绑定在生命周期、历史恢复和快照停止前拒绝；未确认停止的中断阶段不自动重启或清理。

审阅证据生成入口为 `test-env/scripts/review-workspace-temp-stop.py`。`evidence_generated` / `oracle=manual` 只表示调用链证据生成，不自动确认人工结论，也不替代 TEMP-T-021 真实保存验收。源码审阅、单元测试及交叉编译均不能推断实机验收。
