# 内部证书持久保存要求

内部证书可能供当前服务以外的模块使用，因此不能在公网证书发布时丢失。
沿用现有 `ANAS_TLS_CERTS_DIR` 共享目录和环境变量导出，不新增证书服务。
内部证书、私钥和根证书保留固定名称，当前服务证书独立选择；有效内部材料复用，
失效时重新签发。当前服务证书缺失、过期、域名不符或私钥不可用时使用内部证书，
公网证书发布成功后替换当前服务证书，同时保留内部材料。

验证进度见[配套计划](../plans/archived/internal-certificate.md)。容器中的替代 CA 夹具验证
实际 `cert.sh` 发布流程与 TLS 切换，不代表真实 DNS-01 公网签发或现有应用自动重载验收。

## 需求矩阵

| ID | 要求 | 验证方式 |
| --- | --- | --- |
| `LCERT-R-001` | Lego 必须以固定位置保存可复用的内部证书和私钥 | 单元 + e2e |
| `LCERT-R-002` | Lego 必须通过 `ANAS_TLS_INTERNAL_CERT_NAME`、`ANAS_TLS_INTERNAL_KEY_NAME` 和既有共享目录变量导出内部文件位置 | 单元 |
| `LCERT-R-003` | 当前服务证书缺失、过期、域名不符或私钥缺失/不匹配时，Lego 必须发布可用内部证书 | 单元 + e2e |
| `LCERT-R-004` | 公网发布流程必须替换当前服务证书并保留内部证书和私钥 | e2e |
| `LCERT-R-005` | 启动和定时检查必须保留仍有效的公网服务证书 | 单元 + e2e |
