# 门户多语言、主题与界面重做实施计划

**状态：已完成并归档（2026-10-20）。** finance 新制品实机 PORTAL-T-007/PORTALUX-T-004 115/115 通过，22 项需求全部通过，见 §6。 规范来源为[门户多语言、主题与界面重做要求](../requirements/portal-experience.md) PORTALUX-R-001—R-022；

## 1. 确认范围

2026-10-20 用户确认：界面语言扩展为 8 种（目录内容仍只要求中英文）；主题偏好及其他界面偏好按账号保存在服务端；
设计稿中的“常用”和 ⌘K 快速搜索一并实现并补需求。视觉依据为 2026-10-18 发布的设计稿。

复杂度：中等。新增一个偏好文件和一个写接口，复用门户私有数据卷、现有会话与 CSRF；前端仍为无构建步骤的原生 JavaScript，
新增按需加载的语言包和主题预加载脚本。没有新服务、数据库或依赖。主要风险是重写后原有界面选择器变化，
需同步更新界面模拟用例和 finance e2e 脚本，并在新制品上完整复验。
