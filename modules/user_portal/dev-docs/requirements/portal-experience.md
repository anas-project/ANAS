# 门户多语言、主题与界面重做要求

**状态：2026-10-20 用户确认并完成验收；结果见[配套计划](../plans/archived/portal-experience.md)。** 本文约束门户界面语言扩展、
夜间模式、账号级偏好、常用应用、快速搜索及按[视觉重设计稿](https://claude.ai/artifact/7Zi9qZQv21GSikBVHxh3vy)
重写前端。账号、密码、分组和审计的授权语义继续由[独立用户门户要求](user-portal.md)约束，本文不改变它们。
应用目录文本的语言键与回退规则由[应用目录要求](../../../../dev-docs/requirements/app-catalog.md) APPCAT-R-040、R-041 约束。

## 1. 界面语言

门户界面提供 8 种语言：简体中文 `zh-CN`、繁体中文 `zh-TW`、英文 `en`、日文 `ja`、韩文 `ko`、法文 `fr`、
德文 `de`、西班牙文 `es`。全部界面文字都要有这 8 种译文；新增文字缺任一语言视为缺陷，不在运行时回退成英文掩盖。
非中英文译文由开发者起草，未经母语审校；发现措辞问题按普通缺陷修正。

浏览器或用户选择的语言按基础语言匹配：`zh-Hant` 及台湾、香港、澳门地区的中文归 `zh-TW`，其他中文归 `zh-CN`，
`fr-CA`、`es-MX`、`de-AT` 等地区变体归对应基础语言；其余语言直接使用英文。应用名称、简介等目录内容仍只要求
中英文完整，其他语言缺译时按 APPCAT-R-041 回退，不出现空白。

## 2. 主题

主题有三种：跟随系统、固定浅色、固定深色。跟随系统时，操作系统切换明暗后页面即时跟随，不需刷新。
登录、受限改密、退出结果等未登录页面同样使用当前主题。页面加载时先应用本浏览器上次使用的主题，
避免先闪一屏浅色再切换。两种主题都必须满足正文 4.5:1 的对比度。

## 3. 账号级偏好

语言、主题、是否显示分类和常用应用列表按账号保存在门户服务端，同一账号换浏览器登录后自动生效。
未登录时只使用本浏览器保存的选择；登录后以账号偏好为准，并同步到本浏览器缓存。
偏好按人员身份锚点保存，只包含上述字段，不包含姓名、邮箱、密码、令牌或组信息。

偏好写入只接受当前登录本人，必须通过 CSRF 校验，字段与取值使用白名单：语言为 8 种之一或“自动”，
主题为三种之一，常用应用最多 24 个且不重复。偏好不属于安全操作，不要求近期认证，也不写安全审计。

偏好保存在门户私有数据卷的独立目录中，以原子替换方式写入单个文件，随 data 备份。文件损坏或不可读时，
门户继续服务并使用默认偏好，拒绝新的偏好写入，不覆盖原文件。

## 4. 常用应用与快速搜索

用户可以把有权访问的应用加入或移出“常用”，并调整顺序；拖动和键盘按钮两种方式都可以完成排序。
常用列表只返回当前仍有权访问的应用；失去授权的应用不再出现在任何响应中，保存时也拒绝未授权的名称。

按 ⌘K（macOS）或 Ctrl+K 打开快速搜索，可搜索有权访问的应用和门户页面，用方向键选择、回车打开、Esc 关闭。
拥有人员查询权限的用户还可搜索人员，结果来自现有的人员查询接口，不扩大可见范围。

## 5. 界面结构

前端按设计稿重写，采用以下结构：

- 每个页面有独立地址（`#/apps`、`#/account/...`、`#/admin/users/<anchor>` 等），刷新、前进、后退都能回到同一页面；
  未知地址回到首页。
- 普通“工作台”和“管理”分为两种模式；只有拥有平台管理或委派人员动作的用户看到“管理”入口。管理模式单独导航，
  并列出其有权访问的后台管理应用。
- 应用卡片整块可点击，在新窗口打开原始入口地址；文档链接与卡片入口分开。
- 写操作结果分别显示目录保存、IAM 同步、应用会话三段状态。
- 重置密码、解锁账号集中在单独的危险操作区，原有页内确认和本人密码验证保持不变。
- 390px 宽度下无页面横向滚动，主导航位于底部。

重写只改变展示和交互，不改变任何授权判断、确认流程、限流或退出联动行为；现有门户验收用例在新界面上继续适用。
