# LLNG 上线要求

用户于 2026-10-23 确认[完整上线方案](../../../../docs/research/llng-production-readiness.md)。
执行与证据归[配套计划](../plans/llng-production-readiness.md)。范围为 LLNG Module 和其现有
IAM Consumer 集成，不进行当前生产 IAM 切换。遵循根 IAM、目录事件、身份锚点、双向登出及
备份恢复要求；既有强制改密五项要求继续生效，不用新条目替代旧失败项。

用户已明确两项产品边界：**不需要独立恢复管理员**；**AD 要求下次登录改密或密码到期时，
允许已登记 Passkey 继续登录**。独立恢复管理员不作为 LLNG 发布阻塞项。Passkey 仍受目录
禁用、删除、锁定及应用准入约束。目录故障恢复依赖恢复 AD/LLNG 配置与数据库。

2026-10-23 用户进一步确认：**OIDC 优先；允许 Vikunja 接入，并明确接受其无法被后台
强制退出**。此例外只豁免 Vikunja 的应用旧会话后台撤销，不豁免 LLNG 中央会话、授权及新
准入撤销，也不适用于其他应用。例外必须显式配置并持久记录；不能把限制记作成功退出，
不能吞掉已经配置接收端的真实通知失败。已接受的限制不得阻塞其他应用的事件确认。
SAML 改为后续执行，尚未执行项继续保留。
